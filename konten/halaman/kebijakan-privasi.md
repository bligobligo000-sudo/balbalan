<p>Kebijakan ini menjelaskan data apa yang dikumpulkan saat Anda mengunjungi {{nama_website}} ({{alamat_website}}) dan bagaimana data itu digunakan. Berlaku sejak 13 Oktober 2026.</p>
<h2>Data yang kami kumpulkan</h2>
<p>Balbalan tidak meminta Anda mendaftar dan tidak mengumpulkan nama, email, atau nomor telepon. Seperti semua website, server penyedia hosting kami (GitHub Pages) dapat mencatat data teknis seperti alamat IP, jenis peramban, dan waktu kunjungan untuk keperluan keamanan dan operasional.</p>
<h2>Layanan pihak ketiga</h2>
<ul>
<li><p><strong>Google Fonts</strong>: huruf di website ini dimuat dari server Google, sehingga Google dapat menerima alamat IP Anda.</p></li>
<li><p><strong>Foto berita</strong>: foto pada berita dari media lain dimuat langsung dari server media tersebut.</p></li>
<li><p><strong>Tautan keluar</strong>: saat Anda membuka artikel di situs media, kebijakan privasi situs tersebut yang berlaku.</p></li>
</ul>
<h2>Cookie dan iklan</h2>
<p>Saat ini Balbalan sendiri tidak memasang cookie. Jika di kemudian hari website ini menampilkan iklan, termasuk Google AdSense:</p>
<ul>
<li><p>Vendor pihak ketiga, termasuk Google, menggunakan cookie untuk menayangkan iklan berdasarkan kunjungan Anda sebelumnya ke website ini atau website lain.</p></li>
<li><p>Penggunaan cookie iklan oleh Google memungkinkan Google dan mitranya menayangkan iklan kepada Anda berdasarkan kunjungan Anda ke website ini dan/atau website lain di internet.</p></li>
<li><p>Anda dapat menonaktifkan iklan yang dipersonalisasi melalui <a href="https://adssettings.google.com" target="_blank" rel="noopener">Setelan Iklan Google</a>, atau menonaktifkan cookie vendor pihak ketiga melalui <a href="https://www.aboutads.info/choices/" target="_blank" rel="noopener">www.aboutads.info</a>.</p></li>
</ul>
<p>Penjelasan lengkap tentang cara Google menggunakan data dapat dibaca di <a href="https://policies.google.com/technologies/partner-sites" target="_blank" rel="noopener">halaman kebijakan Google</a>.</p>
